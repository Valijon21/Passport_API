Ushbu papka ID karta va Biometrik pasport namunaviy tasvirlarini saqlash uchun mo'ljallangan.

### ⚠️ Maxfiylik va Xavfsizlik Qoidasi:
> O'zbekiston Respublikasining "Shaxsga doir ma'lumotlar to'g'risida"gi qonuniga muvofiq, real fuqarolarning haqiqiy ID kartalari va pasport suratlari ochiq GitHub repozitoriyasiga yuklanmaydi.
> Ushbu papka `.gitignore` orqali himoyalangan.

### 🧪 Mahalliy sinovlar uchun:
1. Sinovdan o'tkazmoqchi bo'lgan hujjat rasmlarini ushbu papkaga joylashtiring (`.jpg`, `.png`, `.webp`);
2. Testni ishga tushirish uchun:
   ```bash
   python backend/tests/test_audit_fields.py
   ```
